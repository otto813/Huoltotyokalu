# Huoltotyökalu

## Ohjelman tarkoitus

Huoltotyökalu on Pythonilla tehty ohjelma tietokoneen perustietojen tarkistamiseen ja raportin tekemiseen.

Ohjelmalla voi:

- tarkistaa levytilan
- näyttää järjestelmätiedot
- tarkistaa Windows-palveluita
- luoda raportin

## Järjestelmävaatimukset

- Windows 10 tai 11
- Python

## Siirrettävyys

Ohjelma on tarkoitettu Windowsille ja toimii toisella Windows-koneella, jos Python on asennettu. Levytilan tarkistus käyttää C:asemaa.

## Rajoitteet

Ohjelma tarkistaa vain C:aseman ja kolme Windows palvelua.

## Kehitysajatukset

Ohjelmaan voisi lisätä lisää tarkistuksia ja palveluita sekä kehittää raporttia selkeämmäksi.
